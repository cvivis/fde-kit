# S6 검증 (130–155분)

채점은 실행 화면과 코드·커밋·대화 기록을 대조한다. 너는 **처음 보는 검토자**이고, 고치지 않는다.

## 절차
1. 실행 확인: `START_CMD="<실행 명령>" PORT=<포트> bash .agents/skills/fde-verify/scripts/verify.sh /`
   - localhost 바인딩 경고가 나오면 1순위 문제로 보고.
2. `docs/AGREEMENT.md`의 만들 것·성공 기준을 하나씩 실제 동작과 대조:
   충족/부분/미충족 + 근거(파일:줄 또는 실행 결과). 결과를 `docs/VERIFY.md` "성공 기준별 충족" 표에.
3. 점검 목록:
   - 키·URL 하드코딩, `.env` 커밋 여부: `git log -p | grep -iE "sk-|OPENAI_API_KEY="`
   - LLM 실패·지연 시 화면, 빈 입력·아주 긴 입력, 새로고침 후 데이터
   - README의 필수 제출 파일이 실제 경로에 있는지
   - 문서(DECISIONS/VERIFY)에 적힌 내용이 실제 코드·커밋과 맞는지
4. 문제 목록을 심각도순으로. 각 항목에 "15분 안에 고칠 수 있음/없음" 표시.

사람이 할 일(상기만): 직접 처음 쓰는 사용자처럼 써보기, 담당자에게 결과 보고하고 수용 피드백을 AGREEMENT "수용 확인"에 붙이기.
