# 사각지대 점검 (S2·S7, 매회 ~2–3분)

## 역할
이 스킬은 담당자가 아예 말하지 않아 INTERVIEW·AGREEMENT에 흔적이 없는 것을 구조적으로 한 번 들여다본다.
모델이 제안만 하고, 반영 여부는 사람이 정한다. 호출 때마다 "Cycle" 하나를 `docs/AGREEMENT.md` 사각지대 점검 표에 더한다.
사람이 정하는 것: 6개 후보 각각의 채택/기각, 채택한 것을 어디(만들 것/안 만들 것/DECISIONS 알려진 한계)에 반영할지.

## 입력
`docs/AGREEMENT.md`(항상). S7 호출일 때는 `docs/VERIFY.md`와 실제 코드 상태도 함께(구현되고 나서야 보이는 사각지대를 잡기 위해).

## 절차
1. 호출 시점을 확인한다: S2(요구 확정 직후, 구현 전) 또는 S7(제출 직전, 구현 후).
2. 정확히 6개 후보를 만든다.
   - **놓친 사용자 시각 3개**: 담당자가 말하지 않았지만 실제 사용자(선수 등)가 겪을 법한 상황.
   - **잘려 나간 가능성 3개**: 범위를 좁히며 함께 버려졌을 수 있는 것.
   - S7 호출에서는 "구현해 보니 드러난 것"(실제 코드·VERIFY 결과에서 나온 간극)을 섞어도 된다.
3. 사람에게 6개를 한 번에 보여 주고 채택/기각을 한 번에 요청한다. **기본값은 기각.**
4. 채택된 것만 반영한다:
   - S2 호출 → `docs/AGREEMENT.md` 만들 것/안 만들 것/가정에.
   - S7 호출 → `docs/DECISIONS.md` "알려진 한계"에, 필요하면 `docs/DEFENSE.md` 예상 질문 재료로.
5. `docs/AGREEMENT.md` 사각지대 점검 표에 이번 Cycle의 6행을 추가한다(기존 Cycle은 지우지 않는다).

## 출력
```text
사각지대 점검 (Cycle <1|2>):
| 후보 | 종류(놓친 시각|잘린 가능성) | 채택/기각 | 반영 위치 |
```
정확히 6행. 불변 조건: 후보는 AGREEMENT·INTERVIEW에 이미 있는 내용의 재진술이 아니다(이미 있으면 사각지대가 아니다).
사람 답 없이 "채택"으로 표기한 행이 없다.

## 원칙
1. 후보는 담당자·INTERVIEW에 없는 것만. 이미 합의된 내용을 다른 말로 다시 적지 않는다.
2. S7 호출은 실제 구현 상태를 근거로 든다(추측이 아니라 "지금 코드에 없다"로 말한다).

## 금지사항
- 6개를 넘거나 모자라게 만들지 않는다.
- 사람 답 전에 반영하지 않는다.
- 한 호출에서 두 Cycle을 동시에 만들지 않는다(S2·S7 각 1회).

## 확인요청
- 6개를 한 번에 보여 주고 채택/기각을 한 번에 묻는다. 왕복이 늦어지면(S2는 S3 시작 전까지, S7은 정리 시작 전까지) 전부 기각으로 간주하고 가정/알려진 한계에 "확인 못 함"으로 남긴다.

## 예시
### 입력
```
AGREEMENT 만들 것: 1) 질문 음성 답변, 2) STT 텍스트화 후 피드백. 안 만들 것: 다른 선수와 비교.
```
### 출력
```text
사각지대 점검 (Cycle 1):
| 네트워크가 느린 환경에서 연습하는 선수 | 놓친 사용자 시각 | 기각 | — |
| 답변을 끝까지 안 하고 중간에 멈추는 경우 | 놓친 사용자 시각 | 채택 | AGREEMENT 가정: "중단 시 저장 안 함, S4에서 확인" |
| 같은 질문을 여러 번 반복 연습하는 경우 | 놓친 사용자 시각 | 기각 | — |
| 비한국어 인터뷰 연습 | 잘려 나간 가능성 | 기각 | 이미 "한국어만" 합의됨 |
| 과거 답변 다시 듣기 | 잘려 나간 가능성 | 채택 | AGREEMENT 만들 것에 추가 검토(시간 되면) |
| 코칭 멘트 톤 커스터마이즈 | 잘려 나간 가능성 | 기각 | — |
```

## 인접 스킬
- vs `$fde-agreement`: agreement가 범위를 정하고, 이 스킬이 그 범위의 빈틈만 점검한다. S2 절차 2단계에서 이 스킬을 부른다.
- vs `$fde-submit`: submit이 제출 정리를 시작하기 전에 이 스킬을 한 번 더 부른다.

## 완료
- 6행이 모두 채택/기각으로 찼고, 채택된 것이 반영됐다(또는 "확인 못 함"으로 남았다).
- 자가 검증: 이번 Cycle의 6행 중 어느 것도 AGREEMENT의 기존 만들 것·안 만들 것·INTERVIEW 인용과 겹치지 않는다.
