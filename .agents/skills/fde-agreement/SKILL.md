# S2 합의 (33–40분)

## 역할
이 스킬은 인터뷰를 이후 모든 작업의 기준이 될 합의문으로 좁히고, 담당자에게 보낼 문장을 채운다.
사람이 정하는 것: 범위 확정, 사각지대 후보 채택/기각, 메시지 문장 수정과 발송.

## 입력
`docs/INTERVIEW.md`. 메시지가 필요할 때 `references/messages.md`의 해당 절만.

## 절차
1. `docs/AGREEMENT.md`를 양식대로 채운다.
   - 맨 위 **한 줄 명세**: "[누가] [언제] [무엇을] 할 수 있게 해서 [어떤 문제]를 줄인다."
   - **만들 것 3개 이하**, 각 항목에 INTERVIEW 근거 인용.
   - **이번에 안 만들 것**: 담당자가 원했지만 뺀 것과 이유(시간·위험).
   - **성공 기준**: 담당자가 화면을 보고 바로 판단할 수 있는 문장. "확인 방법" 열은 비워 둔다(S3에서 채운다).
   - **가정**: 확인 못 한 것. S1에서 넘어온 빈 층 포함.
   - 남은 작업 시간(제출 시작 170분까지 약 2시간 10분)에 끝낼 수 있는 범위로 좁힌다.
2. 1단계 초안이 나오면 `$fde-blindspot`을 호출해 Cycle 1 사각지대 점검(6행)을 받는다. 채택된 것만 만들 것/안 만들 것/가정에 반영한다.
3. 확인 메시지를 **현업 언어로(기술 용어 없이) 5줄 이내**로 쓴다 → `references/messages.md` 템플릿 1.
4. `docs/STATE.md` 기준판 "목표 한 줄"을 한 줄 명세로 바꾼다.

### 담당자 접촉 리듬 — 4회가 상한
| 시점 | 보내는 것 | 남는 곳 |
|---|---|---|
| S2 직후 | 합의 확인 (템플릿 1) | AGREEMENT "팀장 확인" |
| S4 중반, E2E가 막 동작한 직후 | **중간 보고** (템플릿 2) | 대화 기록 + 방향 수정 |
| S6 직후 | **결과 보고 → 수용 확인** (템플릿 5 → 6) | AGREEMENT "수용 확인" |

- **S3 직후 1회만 예외** — 담당자의 기준·순서를 구현에 옮긴 직후 되읽어 확인한다(템플릿 1-B).
- 추가 요구가 오면 템플릿 3, 한 기능이 막히면 템플릿 4. 그 외에는 늘리지 않는다.
- 보낸 뒤 **답을 기다리지 않고 다음 항목을 시작한다.**
- 이후 단계에서: 템플릿 3을 보냈으면 같은 자리에서 "이번에 안 만들 것"에 항목과 이유(메시지와 기록이 한 쌍).
  템플릿 4의 답이 오면 DECISIONS에 "담당자 동의" 한 줄. 끝까지 답이 없으면 "수용 확인"에 **요청했으나 응답을 받지 못함**.

## 출력
```text
파일: docs/AGREEMENT.md — 한 줄 명세 / 만들 것(# · 기능 · 근거 인용) ≤3 / 안 만들 것(항목 · 이유) / 성공 기준(# · 기준 · 확인 방법=empty) / 가정 / 사각지대 점검(Cycle 1, $fde-blindspot 출력) / 팀장 확인
메시지: 템플릿 1을 채운 5줄 이내 초안 (사람이 보낸다)
```
불변 조건: 만들 것은 1~3개, 각 행에 인용이 있다. 사각지대 Cycle 1의 6행 모두 채택/기각이 사람 답으로 찬다. 확인 방법 열은 S2에서 비어 있다.

## 원칙
1. 범위는 시간으로 자른다. 자른 것은 "안 만들 것"에 이유와 함께 남긴다.
2. 성공 기준은 담당자의 말로 쓴다(INTERVIEW 인용을 우선).

## 금지사항
- 근거 인용이 없는 만들 것을 넣지 않는다.
- 담당자 답을 지어내 "팀장 확인"을 채우지 않는다. 메시지를 대신 보내지 않는다.

## 확인요청
- 만들 것이 3개를 넘으면 무엇을 뺄지 묻는다.

## 인접 스킬
- vs `$fde-interview`: 인터뷰는 말을 모으고, 이 스킬은 무엇을 만들지 자른다.
- vs `$fde-blindspot`: 이 스킬은 말해진 것을 자르고, blindspot은 말해지지 않은 것을 점검한다. 2단계에서 호출.
- 다음: `$fde-design`이 AGREEMENT 범위와 번역표로 설계한다.

## 완료
- 만들 것 ≤3(각 인용), 안 만들 것, 성공 기준, 가정이 찼고, `$fde-blindspot` Cycle 1이 끝났고, 메시지를 사람이 보냈다. 답을 기다리지 않고 S3로.
  담당자 답을 "팀장 확인"에 그대로 붙이면 커밋 `[S2] docs: 현업 합의문`.
- 자가 검증: AGREEMENT 만들 것 행마다 INTERVIEW에 같은 인용이 있고, STATE 목표 한 줄 = 한 줄 명세.
