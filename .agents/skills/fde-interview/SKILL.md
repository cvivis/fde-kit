# S1 발굴 (8–33분)

## 역할
이 스킬은 담당자의 말을 잃지 않게 정리하고, 아직 비어 있는 것을 채울 다음 질문을 제안한다.
요구는 묻는 만큼만 나온다. 사소하고 구체적인 질문이 좋은 평가를 받는다.
사람이 정하는 것: 담당자에게 실제로 묻는 것, 어떤 질문을 보낼지.

## 입력
사람이 붙여넣은 담당자 대화(여러 번 나눠 들어온다). 첫 호출 때 `references/expertise-extraction.md`를 한 번 읽는다.

## 절차
요청 문장의 *"제가/저희가 ~하는 **방식·기준·순서**"*가 **인터뷰로만 나오는 요구(R-암묵)**이고, 세 층으로 받는다.

| 층 | 받아야 하는 것 | 없으면 |
|---|---|---|
| **L1 기준** | 먼저 보는 것, 좋은 것/아쉬운 것을 가르는 변수 | 지표를 추측해서 만든다 |
| **L2 구조** | 어떤 순서로, 몇 개까지 말하는가 | 출력 스키마·화면 배치의 근거가 없다 |
| **L3 어휘** | 실제로 쓰는 **문장 원문** | LLM이 일반론을 쓴다 |

1. `docs/INTERVIEW.md` 양식대로 정리한다. 담당자가 한 말은 **인용**, 너의 해석은 **해석**. L1·L2·L3은 반드시 인용으로 남기고 층을 표시한다.
2. 구현 방향을 바꿀 수 있는 질문 3개를 우선순위대로 제안한다. 비어 있는 층이 있으면 그 층이 1순위.
   질문 순서: `references/question-bank.md`, 3층 질문: `references/expertise-extraction.md`.

## 출력
```text
파일: docs/INTERVIEW.md — 대화 기록 표(# / 내 질문 / 팀장 답(인용) / 내 해석), 정리(L1·L2·L3 인용 표시), 남은 질문
보고:
층 상태: L1 <확보 n개|empty> / L2 <확보 n개|empty> / L3 <확보 n개|empty>
다음 질문:
1. <질문> — 채우려는 층·칸
2. <질문> — …
3. <질문> — …
```
불변 조건: 질문은 정확히 3개. 비어 있는 층은 `empty`로 쓴다. 인용 칸에는 담당자 원문만 들어간다.

## 원칙
1. 질문은 장면·기준·빈도를 묻는다. 한 번에 한 질문으로 보낼 수 있는 문장으로 쓴다.
2. 담당자 어휘를 바꾸지 않는다. 다듬은 표현은 해석 칸에만.

## 금지사항
- 해법 단어(AI, 자동화, 기능, 화면, API)를 질문에 넣지 않는다.
- 담당자가 하지 않은 말을 인용 칸에 넣지 않는다.
- 구현 아이디어·지표·스키마를 제안하지 않는다(S3의 일).

## 확인요청
- 붙여넣은 대화에서 누가 한 말인지 불분명하면 인용으로 넣기 전에 묻는다.

## 예시
### 입력
```
나: 선수에게 의견 주실 때 어떤 순서로 말씀하세요?
팀장: 잘한 거 하나 먼저요. 그다음 고칠 거 하나. 여러 개 말하면 다 놓쳐요.
```
### 출력
```text
INTERVIEW 대화 기록: | 3 | 의견 주는 순서 | "잘한 거 하나 먼저요. 그다음 고칠 거 하나. 여러 개 말하면 다 놓쳐요." | 칭찬 1 → 개선 1, 개선점은 한 번에 하나 |
INTERVIEW 정리: L2 순서·개수 (인용): "잘한 거 하나 먼저요. 그다음 고칠 거 하나."
층 상태: L1 empty / L2 확보 1개 / L3 empty
다음 질문:
1. 좋은 답변과 아쉬운 답변을 들으면 가장 먼저 뭐가 보이세요? — L1
2. 고칠 점을 말씀하실 때 선수에게 실제로 하신 말을 문장 그대로 기억하세요? — L3
3. 고칠 점을 말한 다음에 더 하시는 게 있나요? — L2 끝부분
```

## 인접 스킬
- 다음: `$fde-agreement`가 INTERVIEW를 읽어 범위를 정한다. 남은 질문은 합의문 "가정"으로 넘어간다.

## 완료
- **L1·L2·L3이 각각 인용 1개 이상**, 장면을 한 번 이상 들었다. 33분이 되면 무조건 종료하고, 빈 층은 합의문 "가정"에
  "L2 미확보, 임시로 ○○ 순서 사용"처럼 **무엇을 추측했는지** 넘긴다. 커밋 `[S1] docs: 현업 인터뷰 정리`.
- 자가 검증: 정리의 L1·L2·L3 줄마다 대화 기록 표의 인용 원문이 있다.
