# S1 발굴 (12–35분)

사람이 업무 메신저에서 담당자와 직접 대화한다. 너는 **정리와 다음 질문 제안**만 한다.
요구사항은 한 번에 나오지 않고 묻는 만큼만 나온다. 사소하고 구체적인 질문이 좋은 평가를 받는다.

## 할 일 (사람이 대화를 붙여넣으면)
1. `docs/INTERVIEW.md` 형식으로 정리한다.
   - 담당자가 실제로 한 말은 **인용**, 너의 해석은 **해석**으로 구분.
   - "현업의 기준"과 "현업의 실제 피드백 문장"은 반드시 인용으로 남긴다.
2. 아직 모르는 것 중 **구현 방향을 바꿀 수 있는 질문 3개**를 우선순위대로 제안한다.
   - 해법 단어(AI, 자동화, 기능, 화면, API) 금지. 장면·기준·빈도를 묻는 질문으로.
   - 질문 순서 참고: `references/question-bank.md`
3. 구현 아이디어는 아직 말하지 않는다.
4. 커밋: `[S1] docs: 현업 인터뷰 정리`

## 종료 판단 (35분이면 무조건 종료)
- 장면·기준을 한 번 이상 들었고, 실제 피드백 문장을 1개 이상 확보했으면 종료 가능.
- 남은 질문은 합의문의 "가정"으로 넘긴다.
