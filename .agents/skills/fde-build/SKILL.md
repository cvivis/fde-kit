# S4 E2E v0 (55–100분) / S5 심화 (100–130분)

## 항목마다
1. `docs/STATE.md` 작업 목록의 **다음 항목 하나만** 구현한다. 다른 파일은 건드리지 않는다.
2. `docs/DECISIONS.md`를 따른다. 벗어나야 하면 구현 전에 멈추고 이유를 말한다.
3. OpenAI 호출·녹음은 `references/openai-patterns.md` 패턴을 따른다. 모델명은 S0에서 확인한 목록에서.
4. 서버는 **0.0.0.0**에 바인딩, 포트는 고정값으로 정해 README와 보고에 적는다.
5. 끝나면 사람이 확인할 방법을 준다: 실행 명령, Browser 도구에 넣을 PORT와 경로, 기대 결과.
6. 확인되면 `docs/VERIFY.md`에 명령·결과 한 줄, 커밋 `[S4] feat: …`.

## 원칙
- 결정론 코어(점수·판정·계산·저장)는 고정 코드 + 최소 테스트. 테스트 실행 결과도 평가 자료가 된다.
- LLM 응답은 JSON 스키마, 파싱 실패 시 화면에 보일 문구까지.
- 음성 입력이 필요한 과제는 **텍스트 입력 대체 경로**를 같이 둔다(미리보기에서 마이크가 막힐 수 있음).
- 추가하는 방어 로직마다 "합의된 어떤 요구 때문인가" 한 줄. 답 못 하면 안 만든다.

## 막혔을 때
- 같은 에러 2번 → 고치지 말고 원인 가설 3개와 확인 방법만 보고.
- OpenAI 호출 실패 → `python3 .agents/skills/fde-start/scripts/check-openai.py`부터.
- 한 항목 15분 초과 → 더 쪼개거나 가짜 데이터로 대체하고 다음 항목.

## S5 심화 (E2E v0이 된 뒤에만)
- 기능을 늘리지 않는다. 성공 기준 하나를 골라 지금 구현이 어디서 못 채우는지(파일·함수) 짚고, 개선안 2개 비교 후 사람이 고른 것만 구현. 전/후를 VERIFY에.
